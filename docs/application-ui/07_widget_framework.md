# 07. Widget Framework
## AI Brand Intelligence & Visibility Platform

This widget framework defines our reusable dashboard widget components. It specifies the visual structure, metrics displays, interactive behaviors, and responsive adaptations for every widget to ensure system consistency.

---

## 7.1 Unified Widget Library

Our widgets are structured across ten functional categories:

```
+-----------------------------------------------------------------------------------------+
|                                    WIDGET FRAMEWORK                                     |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. Metric Cards     ===> Giant bold values, delta labels, micro charts.               |
|   2. Trend Charts     ===> Responsive line/radar charts mapping visibility scores.       |
|   3. Timeline Feed    ===> Chronological logging tracking campaign completions.          |
|   4. AI Response Card ===> Split panel displaying raw text and extracted mentions.      |
|   5. Citation Card    ===> Detailed metrics card mapping source link authorities.       |
|   6. Entity Card      ===> Relational map showing brand associations in graphs.         |
|   7. Risk / Alert Card===> Red-highlight warning cards displaying urgent PR alerts.     |
|   8. Rec Card         ===> Step-by-step technical optimization suggestions.             |
|   9. Notification Card===> Standard header and in-app system warning banners.           |
|   10. Activity Feed   ===> Interactive checklist mapping active task progress logs.     |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 7.2 Detailed Widget Specifications

### 7.2.1 Metric Card Widget
*   **Visual Layout**: Flat, bordered container panel. Small top label, central giant metric value (bold, 32px), bottom subhead display display delta trends.
*   **Interactive Behavior**: Clickable cards redirect users directly to detailed analytical dashboards.
*   **A11y requirements**: Includes an explicit `aria-label` describing current metrics values and trend changes for screen readers.

### 7.2.2 Trend Chart Widget
*   **Visual Layout**: Resizable chart container (default height 360px) displaying responsive line, bar, or radar charts.
*   **Interactive Behavior**: Hovering over specific data points reveals interactive tooltips with precise metrics and competitor values.

### 7.2.3 Timeline Feed Widget
*   **Visual Layout**: Vertical list of activity items connected by a central timeline axis.
*   **Interactive Behavior**: Clicking an item expands the log to display raw JSON tracking parameters.

### 7.2.4 AI Response Card Widget
*   **Visual Layout**: An organized, split-panel card displaying the model identifier, sentiment rating, and raw generated text highlighting brand mentions.
*   **Interactive Behavior**: Hovering reveals the "Inspect Source" and "Assign Task" action buttons.

### 7.2.5 Citation Card Widget
*   **Visual Layout**: Detailed card displaying the cited domain name, target page path, domain authority rating, and anchor text.
*   **Interactive Behavior**: Clicking the link opens a secure preview of the cited landing page.

### 7.2.6 Entity Card Widget
*   **Visual Layout**: A graphical representation of the brand's entity relationships (subject, predicate, object) mapped to Wikidata or public knowledge bases.
*   **Interactive Behavior**: Drag-and-zoom controls allow users to navigate complex relational trees.

### 7.2.7 Risk / Alert Card Widget
*   **Visual Layout**: High-priority alert banner with a red outline border, warning icon, bold description, and timestamp.
*   **Interactive Behavior**: Click redirects users to the specific hallucinated AI response context for review.

### 7.2.8 Recommendation Card Widget
*   **Visual Layout**: Task card detailing a technical optimization suggestion generated by our AI agent, a brief reason for the change, and a code snippet block displaying the required JSON-LD schema updates.
*   **Interactive Behavior**: Clicking "Apply Recommendation" copies the schema file and marks the task as resolved.

### 7.2.9 Notification Card Widget
*   **Visual Layout**: Muted system banner displaying system check statuses or scheduled report ready logs.
*   **Interactive Behavior**: Click downloads files or routes directly to settings panels.

### 7.2.10 Activity Feed Widget
*   **Visual Layout**: Interactive checklist tracking real-time scraper tasks and progress logs.
*   **Interactive Behavior**: Progression bars update dynamically in real-time as background tasks complete.
