# 01. Brand Overview Module
## AI Brand Intelligence & Visibility Platform

This document defines the primary Brand Overview experience—the core landing dashboard where users analyze high-level brand health, visibility trends, and competitive risks.

---

## 1.1 Brand Overview Layout Blueprint

The overview dashboard is divided into three primary zones:

```
+-----------------------------------------------------------------------------------------+
|                                  BRAND OVERVIEW LAYOUT                                  |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   +---------------------------------------------------------------------------------+   |
|   | Header: Breadcrumbs | Date Filter | Global Actions (PDF Export, Share)           |   |
|   +---------------------------------------------------------------------------------+   |
|   | Zone A: Core Health Scorecard (4 KPI Grid Cards)                                |   |
|   | - AI Visibility Score | Brand Sentiment | Citation Index | Entity Strength      |   |
|   +---------------------------------------------------------------------------------+   |
|   | Zone B: Trends & Comparison Panels (Split 2/3 and 1/3)                         |   |

|   | - Right: Competitor Share of Voice Snapshot Grid                                |   |
|   +---------------------------------------------------------------------------------+   |
|   | Zone C: Actionable Insights & Threat Radar (Split 1/2 and 1/2)                  |   |
|   | - Left: Top 3 Growth Opportunities (AEO/GEO)                                    |   |
|   | - Right: Top 3 Brand Hallucination & Sentiment Risks                            |   |
|   +---------------------------------------------------------------------------------+   |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 1.2 Information Hierarchy & Content Specifications

### 1.2.1 Zone A: Primary KPI Cards
1.  **AI Visibility Score Card**:
    *   *Value*: Display overall Share of Model Voice (SoMV) (bold, 32px; e.g., "48.2%").
    *   *Trend*: Sparkline trend and percentage change indicator (e.g., "+3.4% this week").
    *   *Action*: Click redirects to `/dashboard/visibility` for a detailed per-model breakdown.
2.  **Brand Sentiment Index (BSI) Card**:
    *   *Value*: Overall conversational sentiment score (e.g., "+65 / 100").
    *   *Indicator*: Color-coded status badge (Success Green for positive, Warning Amber for neutral, Error Red for negative).
3.  **Citation Frequency Index Card**:
    *   *Value*: Percentage of AI responses containing direct hyperlink citations to the brand domain (e.g., "35.6%").
4.  **Entity Strength Score Card**:
    *   *Value*: Metric representing semantic relations density inside knowledge graphs (e.g., "78 / 100").

### 1.2.2 Zone B: Multi-Model Trends & Competitor Snapshots
*   **Visibility Trend Chart (Column Span 2/3)**:
    *   *Visualization*: Responsive line chart showing SoMV progress over time. Includes toggle switches to filter data by model types (ChatGPT, Perplexity, Gemini).
*   **Competitor Snapshot (Column Span 1/3)**:
    *   *Visualization*: Vertical horizontal-bar list comparing client SoMV directly with configured competitors (e.g., Brand Alfa: 48.2%, Competitor Beta: 30.1%, Competitor Gamma: 15.4%).

### 1.2.3 Zone C: Actionable Risks & Opportunities
*   **Top 3 Growth Opportunities (Left Panel)**:
    *   *Item 1*: **AEO Schema Injection** (suggesting schema.org additions to product landing pages).
    *   *Item 2*: **Semantic Keyword Optimization** (suggesting high-intent terms to add to blog posts to improve RAG indexing).
    *   *Item 3*: **Wikidata Entity Mapping** (suggesting company updates on public knowledge databases).
*   **Top 3 Brand Risks (Right Panel)**:
    *   *Item 1*: **Outdated Financial Data** (identifying a false revenue summary generated by Gemini).
    *   *Item 2*: **Competitor Citation Takeover** (identifying a prompt campaign where Competitor Beta captured a direct citation link).
    *   *Item 3*: **Negative Sentiment Spike** (identifying negative user feedback summaries on regional forums cited by Perplexity).
