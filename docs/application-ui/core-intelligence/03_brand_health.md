# 03. Brand Health Module
## AI Brand Intelligence & Visibility Platform

This document defines our Brand Health dashboard module, specifying how we measure, present, and visualize key health parameters including Authority, Trust, Coverage, Consistency, and Knowledge Graph Completeness.

---

## 3.1 Nine Core Brand Health Parameters

Our scoring system evaluates brand reputation across nine key metrics:

```
+-----------------------------------------------------------------------------------------+
|                                    BRAND HEALTH PILLARS                                 |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. Authority       ===> Based on high-authority external citations & references.     |
|   2. Trust           ===> Normalized score based on positive sentiment & zero errors.   |
|   3. Coverage        ===> The percentage of active tracking campaigns where brand exists|
|   4. Consistency     ===> Score stability across different LLM platforms over time.     |
|   5. Sentiment Index ===> Average tone rating of brand mentions inside responses.       |
|   6. KG Completeness ===> Entity-relation mappings inside Wikidata & DBpedia.           |
|   7. Entity Maturity ===> Strength of structured schemas and on-page metadata.          |
|   8. Citation Quality===> Direct hyperlink citations to high-authority domains.         |
|   9. Freshness       ===> Review index updates to track training cutoff compliance.     |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 3.2 Visual Presentation of Brand Health

To display these complex parameters clearly, the Brand Health dashboard is organized into an interactive layout:

```
+-----------------------------------------------------------------------------------------+
|                                   BRAND HEALTH DASHBOARD                                |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   - Hero Gauge Indicator: Renders a large circular Brand Health Index (e.g., "82 / 100").|
|   - Radar Chart (Center Panel): Overlays and compares our 9 pillars with competitors.   |
|   - Core Health Cards Grid: Clickable cards display individual scores and trends.        |
|   - Risk Alert Panel: Displays warnings, alert statuses, and freshness indicators.      |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

### 3.2.1 The Radar Chart Overlay
*   **Purpose**: Compares our brand's health profile directly with configured competitors across all nine pillars.
*   **Visual Style**: Clean, semi-transparent overlays displaying distinct color lines (e.g., client brand displayed in azure blue, competitor A in slate gray, competitor B in amber).

### 3.2.2 Core Health Cards Grid
Each card displays an individual pillar score (bold, 24px), a sparkline trend chart, and a sample count indicator:
*   **Authority Card**: `78 / 100` (based on citation counts).
*   **Trust Card**: `85 / 100` (based on positive brand mentions).
*   **KG Completeness Card**: `60 / 100` (highlighting empty Wikidata property fields).

### 3.2.3 Risk & Freshness Panel
*   **Risk Indicators**: Displays active warnings (such as incorrect executive names generated by Gemini, or negative forum mentions cited by Perplexity).
*   **Freshness Tracker**: Displays a time stamp indicating when our content was last indexed and referenced inside LLM search crawlers, helping teams verify indexing and RAG compliance.
