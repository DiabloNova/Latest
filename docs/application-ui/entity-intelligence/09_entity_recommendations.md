# 09. Entity Recommendations Module
## AI Brand Intelligence & Visibility Platform

This document defines our Entity Recommendations module—the dashboard section where users receive and implement actionable optimization recommendations generated by our AI agent to improve knowledge graph completeness and citation authority.

---

## 9.1 Recommendation Categories

To help users prioritize their work, entity recommendations are grouped into four categories:

```
+-----------------------------------------------------------------------------------------+
|                                    RECOMMENDATIONS GRID                                 |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. Critical Issues ===> High-priority errors, contradictory model data, broken links.  |
|   2. Knowledge Gaps  ===> Missing attributes compared to optimal Wikidata/schema templates. |
|   3. Schema Opps     ===> Additions of entity structures to on-page website schemas.     |
|   4. Citation Opps   ===> Suggests high-authority domain sources for strategic outreach. |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 9.2 Recommendation Card Blueprint

Each recommendation is displayed as an interactive card displaying critical attributes:

```
+-----------------------------------------------------------------------------------------+
|                                   RECOMMENDATION CARD                                   |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   [Category Icon]  H2 Recommendation Title (e.g., "Add Schema to Landing Pages")        |
|                                                                                         |
|   Metrics Metrics Banner:                                                               |
|   - Priority Level: [Critical / High / Medium / Low]                                    |
|   - Business Impact: [High / Medium / Low]                                              |
|   - Difficulty: [Easy / Medium / Hard]                                                  |
|   - Expected Authority Improvement: [+12 Authority Index]                               |
|                                                                                         |
|   Description Block: Brief reason for change, and actionable next steps.               |
|                                                                                         |
|   Code Snippet Box: Displays raw JSON-LD schema file updates (with "Copy Code" action).  |
|                                                                                         |
|   Action Row: [Copy Code] | [Mark as Resolved] | [Decline] | [Assign Task]              |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

### 9.2.1 Detailed Recommendation Card Interactions
*   **Copy Code**: Copies the generated JSON-LD schema file directly to the user's clipboard.
*   **Mark as Resolved**: Confirms the changes have been implemented, triggering an immediate background validation audit to verify the fix.
*   **Decline**: Dismisses the recommendation and removes it from the active list.
*   **Assign Task**: Opens our team collaboration menu to assign the optimization task directly to an SEO Specialist or Content Manager.
