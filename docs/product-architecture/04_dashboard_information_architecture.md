# 04. Dashboard Information Architecture
## AI Brand Intelligence & Visibility Platform

This document maps the internal dashboard hierarchy and user flows. It defines the layout structure, core actions, informational requirements, and primary user goals for every section of the platform interface.

---

## 4.1 Global Dashboard Navigation Map

The layout is split into five main functional areas:

```
+-----------------------------------------------------------------------------------------+
|                                  DASHBOARD MAP                                          |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. Executive Insights   ===> Overview, Visibility Score                               |
|   2. Brand Intelligence   ===> AI Search Monitoring, Brand Mentions, Citation Tracking   |
|   3. Competitive / Graph  ===> Competitors, Entity Intelligence                        |
|   4. Execution & Growth   ===> Content Recommendations, Reports                        |
|   5. Administration       ===> Integrations, Team, Billing, Settings                   |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 4.2 Detailed Interface Specifications

### 4.2.1 Section 1: Overview
*   **Purpose**: A high-level executive summary displaying the workspace's overall AI brand health, recent alerts, and tracking status.
*   **Main User Actions**: Toggle tracking intervals (7d, 30d, 90d), view active workspaces, and click on urgent alerts.
*   **Required Information**: Average Share of Model Voice (SoMV), average sentiment trends, and recent negative brand alerts.
*   **User Goals**: Quickly understand overall brand visibility and identify any urgent reputational issues.

---

### 4.2.2 Section 2: Visibility Score
*   **Purpose**: A deep-dive analytical view tracing the brand's Share of Model Voice (SoMV) across different LLM engines and timespans.
*   **Main User Actions**: Filter by specific AI engines (ChatGPT, Perplexity, etc.) and compare overall visibility with key competitors.
*   **Required Information**: Detailed SoMV line charts, recommendation percentages, and model coverage rates.
*   **User Goals**: Measure and verify the success of long-term optimization strategies across major AI systems.

---

### 4.2.3 Section 3: AI Search Monitoring
*   **Purpose**: Manages the dynamic, conversational prompt simulation campaigns and schedules.
*   **Main User Actions**: Create and edit prompt campaigns, select target AI models, and review historical response transcripts.
*   **Required Information**: Campaign structures, prompt templates, language configurations (Persian, English, Arabic), and update schedules.
*   **User Goals**: Set up and run automated prompt monitoring to track recommendations across different query contexts.

---

### 4.2.4 Section 4: Brand Mentions
*   **Purpose**: Analyzes the exact context and sentiment of every individual brand mention across generated outputs.
*   **Main User Actions**: Filter mentions by sentiment, review response texts, and mark incorrect facts for review.
*   **Required Information**: Raw response transcripts, sentiment indicators, and specific factual errors.
*   **User Goals**: Identify and resolve brand hallucinations or negative summaries generated by AI systems.

---

### 4.2.5 Section 5: Citation Tracking
*   **Purpose**: Tracks and lists the external web domains and citation links referenced by AI engines when discussing the brand.
*   **Main User Actions**: Filter by referring domain authority and trace back to the direct cited pages on the company's site.
*   **Required Information**: Citation index scores, referring link paths, and targeted page link statuses.
*   **User Goals**: Measure and improve citation frequency to drive direct search traffic back to the website.

---

### 4.2.6 Section 6: Competitors
*   **Purpose**: Benchmarks the brand's visibility and sentiment performance directly against top competitive targets.
*   **Main User Actions**: Compare SoMV trends, review competitor citation profiles, and view competitive comparison tables.
*   **Required Information**: Comparative recommendation charts, competitor sentiment indexes, and competitive link maps.
*   **User Goals**: Identify strategic gaps and capture market share from competitors in high-intent search results.

---

### 4.2.7 Section 7: Entity Intelligence
*   **Purpose**: Monitors and maps the brand's footprint across Wikidata, Google Knowledge Graph, and regional databases.
*   **Main User Actions**: Audit entity-relation structures, verify schema files, and track entity co-occurrence rates.
*   **Required Information**: Knowledge graph presence statuses, entity-relation trees, and co-occurrence charts.
*   **User Goals**: Build a strong, verified semantic identity to ensure AI engines understand the brand's core offerings.

---

### 4.2.8 Section 8: Content Recommendations
*   **Purpose**: Provides actionable content and on-page technical optimization recommendations generated by our AI agent.
*   **Main User Actions**: Review optimization suggestions, view recommended schema files, and mark tasks as resolved.
*   **Required Information**: Semantic density scores, suggested technical schemas, and step-by-step content updates.
*   **User Goals**: Implement on-page changes that improve search readiness and RAG indexing.

---

### 4.2.9 Section 9: Reports
*   **Purpose**: Generates, schedules, and manages custom corporate and agency PDF visibility reports.
*   **Main User Actions**: Create new report templates, upload logos, configure schedules, and export PDF/CSV files.
*   **Required Information**: Reporting templates, export configurations, and email delivery schedules.
*   **User Goals**: Create polished, professional reporting deliverables to share with clients or internal stakeholders.

---

### 4.2.10 Section 10: Integrations
*   **Purpose**: Manages connections with external corporate software, developer API keys, and Webhook triggers.
*   **Main User Actions**: Create API keys, configure Webhook URLs, and connect CRM or Slack integrations.
*   **Required Information**: API configurations, Webhook paths, and third-party integration statuses.
*   **User Goals**: Connect AI visibility metrics directly with internal corporate workflows and databases.

---

### 4.2.11 Section 11: Team
*   **Purpose**: Manages workspace organization, user access controls, and team member permissions.
*   **Main User Actions**: Invite new team members, edit user roles, and monitor user access logs.
*   **Required Information**: User lists, assigned roles, and workspace access histories.
*   **User Goals**: Securely collaborate with teammates and manage user access across projects.

---

### 4.2.12 Section 12: Billing
*   **Purpose**: Manages platform subscriptions, billing details, invoices, and localized payment integrations.
*   **Main User Actions**: Upgrade subscription plans, update payment cards, and download invoices (in Tomans or USD).
*   **Required Information**: Active plan statuses, transaction histories, and card details.
*   **User Goals**: Securely manage billing details and access local and international invoices.

---

### 4.2.13 Section 13: Settings
*   **Purpose**: Manages general workspace, project configuration, and profile preferences.
*   **Main User Actions**: Edit brand profiles, toggle default language interfaces (Persian/English), and set alert settings.
*   **Required Information**: Profile details, language settings, and workspace parameters.
*   **User Goals**: Customize workspace settings and configure alerting preferences to match team workflows.
