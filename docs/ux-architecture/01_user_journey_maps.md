# 01. User Journey Maps
## AI Brand Intelligence & Visibility Platform

This document defines user journey maps across six target user cohorts, outlining their primary goals, touchpoints, decisions, pain points, and success criteria.

---

## 1.1 Target User Cohorts Map

```
+-----------------------------------------------------------------------------------------+
|                                    USER COHORTS                                         |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. First-time Visitor  ===> Evaluation -> Diagnostics -> Onboarding Signup            |
|   2. Free Trial User     ===> Core Setup -> Tool Audits -> Early Value Realization      |
|   3. Enterprise Client   ===> High Scale Data -> Corporate Security -> API integrations |
|   4. Agency Partner      ===> Multi-client dashboards -> Client Retention -> White-label|
|   5. Returning User      ===> Prompt telemetry -> Alert Management -> Task Resolution    |
|   6. Platform Admin      ===> User provisioning -> System audits -> Billing monitoring   |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 1.2 User Journey Specifications

### 1.2.1 Cohort 1: First-time Visitor
*   **Goals**: Understand the platform's core offering and run a quick diagnostic audit on their company brand to evaluate system capabilities.
*   **Touchpoints**: Marketing homepage, "Free AI Scanner" dynamic form tool, and feature specification sections.
*   **Decisions**:
    *   *Should I trust this brand with our business data?*
    *   *Does this system solve a real problem for our search strategy?*
    *   *Should I sign up for a free trial?*
*   **Pain Points**: Lack of familiarity with AEO/GEO concepts, and complex technical jargon.
*   **Success Criteria**: The visitor executes a free brand scan in under 30 seconds and receives an intuitive report with actionable insights.

---

### 1.2.2 Cohort 2: Free Trial User
*   **Goals**: Set up their active brand project, configure prompt tracking, and evaluate the dashboard within the 14-day trial period.
*   **Touchpoints**: Interactive onboarding wizard, project settings panel, and email tip campaigns.
*   **Decisions**:
    *   *How easy is it to set up prompt campaigns?*
    *   *Do the daily reports provide valuable metrics?*
    *   *Should our team purchase a premium subscription?*
*   **Pain Points**: Feeling overwhelmed during setup, or failing to configure correct competitor targets.
*   **Success Criteria**: The user configures their project and receives three consecutive daily tracking updates displaying clear visibility scores.

---

### 1.2.3 Cohort 3: Enterprise Customer (e.g., Telecom CMO)
*   **Goals**: Monitor corporate brand reputation across international and regional language models, verify compliance, and integrate metrics with internal company systems.
*   **Touchpoints**: Executive insights page, security audit logs, Single Sign-On (SSO) settings, and API developer portal.
*   **Decisions**:
    *   *Is our customer data secure?*
    *   *Does the platform handle large-scale prompt volume (10,000+ queries/month)?*
    *   *How can we connect visibility metrics with our CRM?*
*   **Pain Points**: Complex procurement processes, data privacy requirements, and strict IT review cycles.
*   **Success Criteria**: Enterprise SSO is successfully deployed, and developer teams query visibility databases via public REST APIs.

---

### 1.2.4 Cohort 4: Agency Partner (e.g., Agency Owner)
*   **Goals**: Manage multiple corporate client portfolios from a single dashboard and export white-labeled reports to share with clients.
*   **Touchpoints**: Multi-tenant client workspace list, white-label layout configurations, and PDF report scheduler.
*   **Decisions**:
    *   *Can I safely isolate data across client workspaces?*
    *   *Can we customize the PDF design to match our agency brand?*
    *   *Does this service line create a new revenue stream for our agency?*
*   **Pain Points**: Manual client reporting, and client data leakage risks across workspaces.
*   **Success Criteria**: The agency configures 10 client workspaces and schedules automated, custom-branded weekly PDF reports.

---

### 1.2.5 Cohort 5: Returning User (e.g., SEO Specialist)
*   **Goals**: Review daily visibility score changes, check sentiment alerts, and implement technical content optimization recommendations.
*   **Touchpoints**: Overview dashboard, prompt campaign tracker, brand mentions feed, and content editor.
*   **Decisions**:
    *   *Which brand alerts require immediate public relations response?*
    *   *Which recommended content optimizations will drive the highest visibility?*
*   **Pain Points**: Frequent, non-actionable alert noise, and unclear content optimization guides.
*   **Success Criteria**: The specialist resolves three negative brand alerts and implements a recommended schema update on their website.

---

### 1.2.6 Cohort 6: Platform Administrator (e.g., IT Director)
*   **Goals**: Provision team access, monitor platform subscription billing, check system status, and audit user logs.
*   **Touchpoints**: Organization settings page, billing payment portals, team invite list, and system status page.
*   **Decisions**:
    *   *Are team members assigned the correct roles and permissions?*
    *   *What is our current monthly platform query usage relative to subscription limits?*
*   **Pain Points**: Outdated billing methods, and lack of visibility into admin user activities.
*   **Success Criteria**: The admin configures team member permission roles and exports detailed security log events for compliance.
