# 05. Visual Content Strategy
## AI Brand Intelligence & Visibility Platform

This visual content strategy defines our guidelines for illustrations, product screenshots, AI and data visualizations, diagrams, and iconography, ensuring all media assets reinforce our premium, high-trust identity.

---

## 5.1 Media Asset Guidelines

```
+-----------------------------------------------------------------------------------------+
|                                  MEDIA ASSET SPECS                                      |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   1. Illustrations     ===> Minimal vector line art with accent blue highlights.        |
|   2. Product Shots     ===> High-fidelity, real-time dashboard captures with shadows.    |
|   3. AI Visualizations ===> Animated processing flowcharts mapping RAG crawl loops.     |
|   4. Data Visuals      ===> Clean, high-contrast line/radar charts, no clutter.          |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
```

---

## 5.2 Aesthetic Requirements by Asset Type

### 5.2.1 Illustration Style
*   **Aesthetic Rules**: Use minimal vector line art with subtle slate-gray fills and single accent blue highlights.
*   **What to Avoid**: Avoid generic tech stock illustrations (such as colorful 3D isometric figures or abstract gradient shapes).
*   **Creative Focus**: Illustrate logical database processes, entity relationships, and prompt simulation steps to reinforce technical precision.

### 5.2.2 Product Screenshots
*   **Aesthetic Rules**: Display high-fidelity, real-time captures of our actual SaaS dashboard components (e.g., metric cards, tables, charts).
*   **Presentation Style**: Place screenshots inside flat, bordered browser mockup frames with standard rounding (8px) and clean drop shadows.
*   **Data Integrity**: Ensure the mock data inside screenshots represents realistic, mathematically correct business scenarios.

### 5.2.3 AI Pipeline Visualizations
*   **Aesthetic Rules**: Render animated processing flowcharts to demystify generative search.
*   **Creative Focus**: Visually map how LLM crawlers index web content, parse direct citations, and compute Share of Model Voice (SoMV), establishing deep, technical credibility.

### 5.2.4 Data Visualizations (Charts)
*   **Aesthetic Rules**: Display clean, high-contrast line and radar charts.
*   **Grid Style**: Muted, light gray background grid lines to avoid cluttering raw data.
*   **Data Indicators**: Clearly label Y/X axis metrics and include precise hover-tooltips for direct data-point inspection.

### 5.2.5 Diagram & Technical Figures
*   **Aesthetic Rules**: Use simple, vector-drawn boxes and connecting arrows.
*   **Creative Focus**: Document system architectures, multi-tenant database isolations, and API request routing configurations.

### 5.2.6 Iconography Styles
*   **Aesthetic Rules**: Standardize on thin, `2px` vector line-art icons built on a `24px` grid boundary.
*   **Usage**: Use consistently as subtle visual tags next to titles, inside buttons, and on metric cards.
*   *Reference*: Mapped comprehensively in the [Iconography System](../design-system/08_iconography_system.md) design file.
